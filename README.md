# Miguel Valtierra's Portfolio

## Introduction
Welcome to my portfolio! I'm an industrial designer based in San Francisco, with roots in Guanajuato, México. I design objects that tell a story and build every one myself, from cardboard maquette to finished piece. My background in cybersecurity, web development, and computer networking shapes how I think about systems, users, and the details that connect them.

## Certifications
### Google Certifications
- **Certifications Earned:**
  - Google Cybersecurity Certificate (Coursera, August 2024), 8 courses:
    - Foundations of Cybersecurity
    - Play It Safe: Manage Security Risks
    - Connect and Protect: Networks and Network Security
    - Tools of the Trade: Linux and SQL
    - Assets, Threats, and Vulnerabilities
    - Sound the Alarm: Detection and Response
    - Automate Cybersecurity Tasks with Python
    - Put It to Work: Prepare for Cybersecurity Jobs
  - Foundations of Project Management (Google, Coursera)
- **Description:**
  - **Foundations of Cybersecurity:** core concepts, including security threats, vulnerabilities, and attack vectors. The groundwork for protecting information systems.
  - **Play It Safe: Manage Security Risks:** risk management strategies: how to identify, assess, and reduce security risks within an organization.
  - **Connect and Protect: Networks and Network Security:** network protocols, firewalls, intrusion detection systems (IDS), and secure network configurations.
  - **Tools of the Trade: Linux and SQL:** hands-on experience with Linux and SQL, two essential tools for cybersecurity professionals.
  - **Assets, Threats, and Vulnerabilities:** how to identify valuable assets in an organization, recognize potential threats, and understand system vulnerabilities.

  - **Automate Cybersecurity Tasks with Python:** using Python to automate common security tasks.
  - **Put It to Work: Prepare for Cybersecurity Jobs:** applying these skills to real-world scenarios.
  - **Foundations of Project Management:** project planning, execution, monitoring, and communication. These skills apply to security projects and to any other type of project, including design.
